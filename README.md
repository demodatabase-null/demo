# ระบบยื่นคำร้องขอตรวจสอบเกรด

เว็บไซต์ตัวอย่างเชื่อม Supabase Auth, PostgreSQL และ Private Storage

## ตั้งค่าฐานข้อมูล

1. เปิด Supabase Dashboard ของโปรเจกต์นี้ แล้วไปที่ **SQL Editor**.
2. เปิดไฟล์ `supabase-schema.sql` คัดลอกเนื้อหาทั้งหมด แล้วกด **Run**.
3. ตรวจสอบว่าได้ตาราง 14 ตารางใน schema `public` และ bucket `appeal-evidence` แบบ private.
4. ใน Supabase ไปที่ **Authentication → Sign In / Providers → Email** แล้วปิดการยืนยันอีเมลสำหรับเว็บทดลองนี้ จากนั้นเปิดเว็บ GitHub Pages เพื่อสมัครบัญชีนักศึกษา.

## บัญชีทดลอง

- อาจารย์: ชื่อบัญชี `advisor` · รหัสผ่าน `11223344`.
- เจ้าหน้าที่: ชื่อบัญชี `admin` · รหัสผ่าน `11223344`.
- บัญชีทดลองใช้ alias ภายใน `advisor@demo.invalid` และ `admin@demo.invalid` จึงไม่ต้องรับอีเมลยืนยัน.
- เว็บนี้เปิดสาธารณะและบัญชีทดลองใช้รหัสผ่านที่ทราบร่วมกัน ห้ามใส่ข้อมูลจริงหรือใช้รหัสนี้ในระบบจริง.

## บัญชีอาจารย์และเจ้าหน้าที่

การสมัครจากหน้าเว็บจะได้บทบาทนักศึกษาเท่านั้น บัญชีทดลองอาจารย์และเจ้าหน้าที่ต้องถูกเตรียมไว้ใน Supabase Auth และ `public.users` โดยใช้ alias ข้างต้น สำหรับอาจารย์ให้สร้างแถวใน `public.teachers` และรายวิชาใน `public.course_offerings` เพิ่มด้วย ห้ามเปลี่ยนบทบาทจากข้อมูลที่ผู้ใช้ส่งมาจากหน้าเว็บ.

## หมายเหตุด้านความปลอดภัย

- ใช้เฉพาะ publishable key ใน `index.html`; ห้ามใส่ secret/service_role key ใน GitHub หรือเว็บเบราว์เซอร์.
- ตารางเปิด Row Level Security และจำกัดข้อมูลตามบทบาทและเจ้าของข้อมูล.
- หลักฐานถูกอัปโหลดไปยัง bucket ส่วนตัว จำกัด PDF/JPEG/PNG และ 10 MB ต่อไฟล์.
- ข้อมูลบัญชีทดลองเดิมที่ฝังไว้ในไฟล์ถูกถอดออก การทำงานจริงต้องใช้บัญชี Supabase Auth.
- `grade_appeal_oracle.sql` เป็นสคริปต์ Oracle แยกต่างหาก ใช้ `supabase-schema.sql` สำหรับ Supabase/PostgreSQL.
